# 🧠 Student Exam Score Analysis (Python Project)

### 👩‍💻 Author: Khadija Rao

---

## 📖 Project Overview
This project explores how **study hours**, **sleep hours**, and **attendance** affect students' exam performance.  
It uses **Python, Pandas, Matplotlib, and Seaborn** for data analysis and visualization.

---

## 🧹 Data Cleaning
- Removed unnecessary columns
- Converted non-numeric values into numeric
- Dropped missing or invalid entries

---

## 📊 Analysis
### Correlation Findings:
- 📚 **Hours Studied** → Strong positive correlation with exam score  
- 😴 **Sleep Hours** → Weak or neutral correlation  
- 🎓 **Attendance** → Moderate positive correlation
